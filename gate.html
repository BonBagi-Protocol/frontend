Raw multi-recipient request

Build one ZIP-321 request that pays three shielded addresses in a single transaction. Everything stays in this tab — nothing is sent anywhere or saved. Use this to check that a wallet handles one request with several shielded recipients.

Pass criteria
  1. Zingo PC (2.0.26 pre-release) shows all three recipients and amounts before you confirm.
  2. It sends one transaction.
  3. Each receiving wallet shows exactly its amount and its memo.

Backup wallet: Zkool. Do not use Zodl (iOS rejects multi-recipient requests; Android shows only the first recipient).

Runs entirely in this tab. Keys, addresses and requests are never sent anywhere or saved. The page loads only its own files from this site, and its security policy stops its code from calling any server.
